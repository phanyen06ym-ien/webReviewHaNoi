# 05. Danh sách chức năng

## Nhóm nghiệp vụ

- Review: CRUD, Detail, My Posts, Like, Save, Comment, Hashtag, Rating.
- Explore: search không dấu, suggestion, filter kết hợp và sort.
- Task: CRUD, deadline, priority, status, undo, search/filter/sort.
- Authentication: register, login, logout, session và protected pages.
- Profile: cập nhật thông tin và đồng bộ tác giả.
- Statistics: KPI và bảy biểu đồ tổng hợp.
- Data: export JSON toàn hệ thống hoặc riêng Task.
- UI chung: responsive navigation, toast, confirm, skeleton và Back to Top.

Bảng ánh xạ chức năng-trang-file xem [FEATURE_LIST.md](../FEATURE_LIST.md); catalog function JavaScript xem [JS_STRUCTURE.md](../JS_STRUCTURE.md).
