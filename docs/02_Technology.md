# 02. Công nghệ

| Công nghệ | Vai trò trong dự án |
|---|---|
| HTML5 | Cấu trúc semantic, form, navigation và accessibility. |
| CSS3 | Variables, Flexbox, Grid, animation và responsive media query. |
| JavaScript ES6+ | DOM, event, validation, CRUD, search/filter/sort và render. |
| LocalStorage | Lưu dữ liệu JSON và session giả lập. |
| Chart.js | Vẽ biểu đồ tại trang Statistics. |
| Font Awesome | Icon giao diện qua CDN. |
| Google Fonts | Font Inter qua CDN. |
Project không dùng framework, bundler, database hoặc package runtime. Cách này phù hợp mục tiêu quan sát trực tiếp mối quan hệ HTML-CSS-JavaScript của môn học.
